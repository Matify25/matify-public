Troubleshooting

Every error in Document Generator shows a code (for example DGJ-SCOPE-OVERCAP), a message that says what to do, and a reference. If you contact support, send both the code and the reference.

Template problems (E-…, W-…, I-… and DGJ-TPL-…) are explained in the Template cookbook.

Common situations

"Generate document" is missing from the work item's ••• menu. The app may not be installed or licensed on the site, or your Jira admin limited generation to selected groups (then the dialog opens with DGJ-PERM-NOACCESS).

"Generate document…" is missing from the issue navigator. Use Apps → Document Generator → New document with the same JQL or a saved filter. The navigator integration uses an Atlassian module that is still in preview; the Documents page offers the same flow.

No templates in the list. Your Jira admin hasn't published a template for this project yet and the curated packs are switched off. Ask your Jira admin.

The download doesn't start. Downloads only start from a click on Download. Allow downloads for your Jira site in the browser (some browsers ask once per site), check that no extension blocks them, or use Attach to … instead. Downloads are verified in Chrome, Edge and Firefox; Safari is not verified yet (Known limitations).

Jira asks me to "Allow access". This is Atlassian's one-time consent: Document Generator reads work items as you, so documents never include items you can't see. Accept it to continue. If a background document stopped with DGJ-JOB-CONSENT, open Document Generator once, allow access, then use Retry.

Work items are missing from my document. The result lists the selected or single work items that couldn't be read (you can't see them, or Jira marked them as blocked by your organisation's data security policy), work items over a limit, work items that were too large for a background document, and work items of projects the template isn't published for. Work items that a search simply doesn't return — because you can't see them or a data security policy hides them from apps — can't be listed: Jira doesn't report them to apps. Templates can print the notes with {{doc.notes}}.

Characters are missing in the PDF. The PDF fonts cover Latin, Greek and Cyrillic, and some symbols (for example "→") are missing. Use DOCX (DGJ-RENDER-FONT).

A photo is rotated in the PDF. PDF output ignores the camera's orientation data in JPEG files. Rotate the image before attaching it to the work item, or use DOCX.

Access and permissions

DGJ-PERM-NOACCESS

"Your Jira admin has limited document generation to selected groups. Ask them for access." Cause: you are not in one of the groups selected in Settings → Who may generate documents. The same code appears with "couldn't confirm your group membership" if Jira didn't answer; reload the page. Fix: ask your Jira admin to add you to one of the groups.

DGJ-PERM-ADMIN

Cause: the action needs the Jira global permission Administer Jira, or the app could not confirm your permissions. Fix: ask a Jira administrator; if you are one, reload the page and accept Jira's access prompt if it appears.

DGJ-PERM-ATTACH

"You can't attach files to {key}. Download the document instead, or ask a project admin for the 'Create attachments' permission." Fix: download the document, or get the Create attachments permission on that project.

DGJ-PERM-POLICY

"Your organization's data security policy blocks Document Generator from {n} work items. They were left out of the document." Cause: Jira reported that an Atlassian data security policy of your organisation blocks the app from a work item, or from the JQL check or count itself (then this code appears instead of "invalid JQL"). Jira does not report work items a policy hides from a search, so those can't be counted here. Fix: nothing in the app; your organisation's admin decides the policy.

DGJ-PERM-INSTALLING

"Document Generator is finishing installation… Try again in a minute." Cause: right after an installation Jira refuses the app's requests for a short time. Fix: wait a minute and try again.

DGJ-PERM-TEMPLATE

Cause: the template is not published, the pack was switched off by your Jira admin, or the template can't be used for this kind of scope (for example a single-item template for a search). Fix: pick another template.

DGJ-PERM-JIRA

"Jira didn't allow Document Generator to read the … for you." Cause: Jira refused a read with your permissions. Fix: check that you can open the work item, filter or project in Jira; reload the page.

DGJ-PERM-ANON

"Sign in to Jira to use Document Generator." Fix: sign in and reload the page.

DGJ-PERM-JOB

Reserved in the error catalogue; the current version does not show it. If you see it, contact support with the reference.

Scope

DGJ-SCOPE-UNBOUNDED

"This search has no filter, and Jira can't run unbounded searches for apps. Add a condition such as a project, then try again." Fix: add a condition, for example project = ABC.

DGJ-SCOPE-INVALID

Cause: Jira rejected the JQL (the message lists Jira's explanation), or the JQL is longer than 4,000 characters. Fix: correct the JQL; use Validate JQL on the New document page.

DGJ-SCOPE-OVERCAP

"This search has about {n} work items. Documents can include up to {cap} ({format}). Narrow the search, or split it by project or version." Also shown when Jira passes more than 1,000 selected work items to the app. Fix: narrow the search or split the document. Limits: Large sites.

DGJ-SCOPE-EMPTY

Cause: the search returns no work items you can see. Fix: check the JQL in the issue navigator.

DGJ-SCOPE-FORMAT

"This format isn't available for this template." Cause: the format is switched off for the site or not allowed by the template. Fix: choose another format.

DGJ-SCOPE-NOTFOUND

Cause: Jira couldn't find the work item, filter or project, or you don't have access to it — for example a saved filter that isn't shared with you ("This saved filter isn't available to you. Use the JQL instead."). Fix: use a JQL, or check the item in Jira.

Limits

DGJ-LIMIT-POOL

"Jira's API limit for apps is used up for this hour. Background documents resume automatically at {time}. You can run this one in the background now." A short variant, "Jira is busy right now. Try again in a moment.", appears when Jira briefly throttles requests. Fix: choose Run in background, or try again after the time shown. See Large sites.

DGJ-LIMIT-SITE

"Document Generator has used this hour's API budget on this site. Try again after {time} UTC, or run it in the background." Fix: run it in the background (it continues at the next full hour), or try again later. Jira admins can see the budget on the Overview page. The app's pages, My documents, Cancel and Delete keep working meanwhile: the identity and permission checks they need use a small separate allowance (300 points per hour).

DGJ-LIMIT-QUEUE

Cause: you already have 3 background documents in progress, or 10 are waiting on the site. Fix: wait until one is ready, or cancel one you no longer need in My documents.

DGJ-LIMIT-STAGED

"Too much content — use fewer items or fields only." Cause: the collected data of a background document exceeded 50 MB. Fix: fewer work items, no comments, or a template that uses fewer rich-text fields. Retry is not offered: it would stop again.

DGJ-LIMIT-ITEM-SIZE

"{n} work items were too large to include in a background document (very long text or comments) and were left out. Generate them on their own, or without comments." Cause: the content of one work item alone is larger than about 200 KB compressed. Such work items are listed as "too large" and the document is built without them. If it is the work item the document is about (a single work item or an epic), the background document stops with "This work item is too large for a background document … Generate it directly, or without comments." Fix: generate that work item directly (not in the background), without comments, or with fewer comments per work item.

DGJ-LIMIT-ATTACHSIZE

"The document ({size}) is larger than your site's attachment limit ({limit}). Download it instead."

DGJ-LIMIT-RESPONSE

"The response was too large. Try fewer work items per batch." Cause: unusually large work items (very long rich text). Fix: try again with fewer work items or a background document; contact support if it repeats.

Building the document in the browser

DGJ-RENDER-MEMORY

"Your browser ran out of memory while building the document. Try fewer work items, DOCX instead of PDF, or run it in the background and render it later." The app also stops before building when it estimates more than 300 MB of memory.

DGJ-RENDER-FONT

"Some characters (for example Chinese or Arabic) can't be shown in PDF output. Use DOCX for this document." The PDF is still created; the missing characters are listed with the result.

DGJ-RENDER-FAILED

Cause: the document couldn't be built in your browser. Fix: try again; if it repeats, try DOCX or fewer work items and contact support with the reference.

DGJ-RENDER-INPUT

Cause: something the engine needs was missing (template file, PDF fonts). Fix: reload the page and try again; contact support if it repeats.

DGJ-RENDER-IMAGE

"Some images could not be embedded and are shown as placeholders." The result lists each image with the reason (type, size, count or damaged file).

DGJ-RENDER-CANCELLED

You cancelled the document. No file was created.

Background documents

DGJ-JOB-EXPIRED

"This background document expired after 24 hours. Generate it again."

DGJ-JOB-FAILED

"The background document stopped after several attempts ({reason}). Retry from where it stopped, or contact support with code {code}." Fix: Retry from checkpoint in My documents — available for 24 hours after the document stopped. After that it shows "This background document stopped more than 24 hours ago, so it can't be retried. Generate it again."

DGJ-JOB-QUEUE

"Document Generator couldn't start the background document. Use Retry in a moment." — or, for a document that had already started, "Document Generator couldn't continue the background document. Use Retry to continue from where it stopped." Cause: the background queue didn't accept the next step after three attempts (this can happen right after an app update). The document keeps what it collected. Fix: use Retry. The daily check also resumes it; a document that can't be handed to the queue for 24 hours is stopped and its collected data deleted.

DGJ-JOB-STUCK

Cause: a background document made no progress for 2 hours, needed too many steps, or couldn't be handed to the queue for 24 hours, and was stopped by the daily check (documents whose next step was merely lost are resumed instead). Fix: Retry from checkpoint (within 24 hours); contact support if it stops again.

DGJ-JOB-CONSENT

"Document Generator can't read Jira for you in the background yet: you haven't allowed it access. Open Document Generator once (for example from a work item's Apps menu), choose Allow access, then use Retry." Cause: background documents read Jira as the person who started them; Atlassian requires that person's one-time consent. Fix: as the message says.

DGJ-JOB-SCHEMA

Cause: the background document was started before an app update that changed how background documents are stored. Fix: generate it again.

DGJ-JOB-OWNER

Cause: the background document's record failed its integrity check, so the app refused to read Jira for it. Fix: generate it again and contact support with the reference.

DGJ-JOB-NOTFOUND

"This background document wasn't found. It may have been deleted." Background documents are only visible to the person who started them.

DGJ-JOB-STATE

Cause: the action doesn't fit the document's state — for example rendering one that isn't ready yet, or retrying one that didn't stop. Fix: reload My documents.

DGJ-JOB-CANCELLED

Reserved in the error catalogue; the current version shows cancelled documents with the state Cancelled instead.

Licence, Jira and general

DGJ-LIC-INACTIVE

"Document Generator isn't licensed on this site. A Jira admin can renew or start a trial on the Marketplace." Generating documents, starting, rendering or retrying background documents, and changing the app's configuration need an active licence or trial. Templates, settings and usage stay readable to Jira admins; template download, unpublish, archive and delete, Delete all app data, and cancelling or deleting background documents (My documents) keep working. See the admin guide.

DGJ-JIRA-5XX

"Jira didn't respond correctly. Try again in a moment." The app already retried three times.

DGJ-JIRA-ERROR

Cause: Jira returned an unexpected answer. Fix: try again; contact support with the reference if it repeats.

DGJ-BUSY

Cause: all app data is being deleted (then the app's other functions are unavailable until it has finished), or another upload of the same template is in progress. Fix: wait until it has finished.

DGJ-INPUT

Cause: a request or setting was not valid — for example a limit outside its range ("The limit … must be a whole number between 1 and …") or an invalid file-name pattern. Fix: correct the value; for other cases reload the page.

DGJ-UNKNOWN

"Something went wrong in Document Generator. Try again; if it keeps happening, contact support with this reference."

Messages from the app's pages

DGJ-UI-CONSENT

"Jira needs your permission before Document Generator can read work items for you. Choose Allow access when Jira asks, then try again." Cause: you haven't given the app Atlassian's one-time consent yet; Jira shows its "Allow access" prompt. Fix: allow access; the app reloads.

DGJ-UI-BRIDGE

"Document Generator couldn't reach its backend. Reload the page and try again."

DGJ-UI-RESPONSE

"Document Generator received an unexpected response. Reload the page and try again."

DGJ-UI-TEMPLATE-FETCH

"The template couldn't be loaded. Reload the page and try again."

DGJ-UI-DECOMPRESS

"The staged data of this background document couldn't be read in this browser. Try a current version of Chrome, Edge or Firefox."

DGJ-UI-ATTACH

"The document couldn't be attached to {key} ({status}). Download it instead, or try again." If the connection was lost, check the work item before trying again — the app warns you if the same file was attached in the last 10 minutes.

DGJ-UI-DOWNLOAD

"Your browser didn't start the download. Allow downloads for this site, or attach the document to a work item instead."

DGJ-UI-CANCELLED

You cancelled the document. No file was created.

DGJ-UI-UNKNOWN

An unexpected error in the page. Reload the page; contact support with the reference if it repeats.
