FAQ

Does this replace Copy Space or Copy Page Tree? It does the same copying, and adds the part those tools leave to you: a request form with a naming policy, an approval step, an owner and review date on every space, an inventory, drift detection and an audit trail. If all you need is to duplicate a space once, a copy tool is enough. If you need new spaces to be consistent and accounted for, that is what this is.

Do I need Confluence Premium? No. Copying a space's access configuration on Premium is a native feature; this app does it on every plan through the role-based space access API.

Can a normal user create a space with this? Only by asking. A request always needs an administrator approval, or an auto-approval rule an administrator set up in advance. That gate is the product.

What exactly gets copied? Pages and their nesting, attachments, labels and content properties — copied by Confluence's own server-side task. Plus the blueprint's space access configuration, and any space labels you configured. Not copied: whiteboards, databases, folders, blog posts, page history, space themes, and page-level restrictions. The app shows this list before you confirm a blueprint.

Why not copy page restrictions? Because it would create invisible access rules in a brand new space that neither the requester nor the approver reviewed. Space-level access is copied, and it is visible and reviewable. Page-level restrictions are deliberately left off.

How big can a blueprint be? 500 pages. The cap is enforced when you capture the blueprint, so you find out immediately rather than when a provisioning run times out. For a larger source space, point the blueprint at a subtree.

How long does provisioning take? A small blueprint finishes in seconds. Larger ones take a few minutes, driven by Confluence's copy task rather than by the app. Progress is shown while it runs.

What if provisioning fails halfway? The request stops at the failed step with an error code, and an administrator can retry from that step. The app does not start over and does not create a second space. It also does not delete the partially created space; removing it is your decision, not the app's.

Does the app ever delete anything? No. It never deletes or archives a space or page, never removes a permission, and never reverts a drift. The only deletions it performs are of its own stored data, and only when an administrator asks.

Does my content leave Atlassian? No. The app runs on Atlassian's platform, stores data in Atlassian's storage in your region, and makes no external network calls at all — no analytics, no error reporting, no fonts, nothing. Page content is never even read by the app: Confluence copies it internally.

What does the app store about people? Atlassian account ids, to record who requested, approved and owns each space, and who performed each audited action. No names, no email addresses, no profile data. See Privacy and data.

Who can see the admin console? Confluence product administrators. The check happens in the backend, so a bookmarked URL does not get a non-administrator in.

Can I use it with Jira Service Management, so a ticket creates a space? Not in version 1.0. It would require a public web-trigger endpoint, and the app's own eligibility check confirms that a web trigger disqualifies it from Atlassian's Runs on Atlassian programme. That trade-off is not worth making silently, so the integration waits for a version where it can be an explicit choice.

How often does the inventory update? Weekly, in bounded batches, plus on demand. Space creation and deletion register immediately. The weekly cadence exists because an app shares one hourly request budget across every site it is installed on, and sweeping continuously would spend other customers' share of it.

What happens on a very large site? The sweep spreads across the week and yields whenever Confluence signals it is near the limit. Space requests always take priority over sweeping, so a provisioning run is never delayed by an inventory scan.

What happens when the licence lapses? Reading keeps working so administrators can see the state of things, changes are refused, and the weekly sweep stops. Nothing is deleted. Everything is there when the licence returns.

What happens if I uninstall? Forge removes the app's storage: blueprints, policies, requests, inventory and audit trail. The spaces, pages, labels, space properties and role assignments created while it was installed stay, because they are your content.

Is there a free tier? Yes, up to ten users, following the category convention.
