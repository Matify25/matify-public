Changelog

1.0.0 — initial release

First public release of Space Blueprints for Confluence.

Blueprints

  • Capture any Confluence space as a reusable blueprint
  • Fidelity report shown before a blueprint is confirmed: page count against the 500-page cap, and

whether the space contains whiteboards, databases, folders or blog posts

  • Default owner, owner space role, review interval and naming policy per blueprint
  • Archive and re-capture

Naming policies

  • Pattern for the space name, optional pattern for the key, and a worked example
  • Live validation in the policy editor and in the request form
  • Patterns are length-bounded and screened for constructs that could hang the evaluator

Requests and approvals

  • Request form for any eligible user, with live name validation and key suggestion
  • Approval queue with a preview of exactly what will be created
  • Reject with a reason, visible to the requester
  • Auto-approval rules per blueprint and group
  • Requesters can withdraw a request that has not started provisioning

Provisioning

  • Creates the space with the blueprint's access configuration copied by Confluence
  • Assigns the owner their space role
  • Copies the page tree with attachments, labels and content properties through Confluence's own

server-side copy task

  • Applies space labels and writes the blueprint reference and review date onto the space
  • Live progress with the copy task's own percentage
  • Every step idempotent; retry from the failed step without starting over or creating a second space
  • Page-level restrictions are never copied, by design

Inventory and drift

  • Every space with owner, blueprint, provisioned date, review date, last activity and drift status
  • Drift detection for role assignments, labels, ownership and overdue reviews
  • Bulk assign owner and review date
  • Weekly scheduled sweep in rate-limit aware batches, plus run-now and per-space re-check
  • CSV export

Audit and diagnostics

  • Append-only audit trail of requests, decisions, provisioning steps and configuration changes
  • Configurable retention between 6 and 60 months, 24 by default
  • CSV export
  • Diagnostics page with sweep state, rate-limit budget, queue health, recent failures and app version

Platform

  • Runs on Atlassian: Atlassian hosted compute and storage, no external data egress
  • Personal data reporting implemented; erasure requests honoured
  • Free for up to ten users
