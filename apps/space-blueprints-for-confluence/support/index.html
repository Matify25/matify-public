Support

Space Blueprints for Confluence is supported by Matify. One address, read by a person.

Before you write

Two pages answer most questions faster than a ticket does: troubleshooting, which lists every error code the app can show and what to do about it, and the FAQ. If the app showed you an error code, start there.

Ask a question or report a problem

  • Email: mira.maty@web.de — for anything, and the only channel for anything confidential.
  • Public tracker: open a support request, bug report or feature request. You can also browse existing work items.

What to include

  • The app version, from Diagnostics in the admin console.
  • The error code, if there was one.
  • What you were doing, and what you expected instead.
  • The diagnostics JSON from the Copy diagnostics button. It contains no page content, no names and no email addresses.

What never to include

The tracker is public and its history stays readable after an edit. Never post a password, an API token, an account id, an email address, a customer name, page content, an internal hostname, or anything else your organisation would not publish. If a question cannot be asked without one, email it instead.

Security vulnerabilities

Never a public issue. Email mira.maty@web.de privately, and please do not include customer data or credentials in the report.
