Support

Config Undo for Jira is published and supported by Matify.

Contact

  • Email: support@matifyapps.de — for anything, and the right channel for anything confidential.
  • Open a support request without an account: Matify support form. Your own email program sends the ticket.
  • Public tracker (GitHub account needed to post): report a bug, ask a question or request a feature, or browse existing work items. Pick Config Undo for Jira as the app, or Another Matify app and name it.

Response times and hours (Monday to Friday, 09:00–17:00 CET/CEST) are in the Matify service level agreement.

Before you write

The troubleshooting page explains every error code (CUJ-…), and the FAQ answers common questions. For a restore that didn't do what you expected, follow the incident playbook in the restore guide.

What to include

  • The diagnostics file: Coverage & Health → Download diagnostics. It contains the app version, settings, counts, error codes and rate-limit history — no account ids, names, email addresses or configuration content.
  • The error code and the ref shown next to it.
  • For a restore: the request id and its ledger entry numbers. Write "restore incident" in the summary.
  • What you did, and what you expected instead.

What never to post publicly

The tracker is public. Never post passwords, API tokens, account ids, email addresses, customer names, configuration content or internal host names there. Email anything confidential instead.

Security issues

Never in a public ticket. Email support@matifyapps.de with "security" in the subject, or use the support form with the type "Security vulnerability". Matify follows Atlassian's Security Bug Fix Policy for Marketplace apps.
